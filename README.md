# ars-nova-core

**Ars Nova Singers - custom WordPress plugin.** Canonical source (private use; not distributed).

- Current version: 1.0.0 (matches DEV arsnovasingers.kinsta.cloud; header reports 1.0.0)
- Environment: DEV only; not on LIVE.
- Site-specific data layer: Productions/People/Callouts CPTs, ACF options page, ACF field groups, image sizes; kept in a plugin so data survives theme changes. v1.0.0.

Releases: each tag v<version> attaches the installable zip (top folder ars-nova-core/). Install/update via the Ars Nova Ops installer or WP-admin upload.
